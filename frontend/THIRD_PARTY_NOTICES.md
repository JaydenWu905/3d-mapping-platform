# Third-Party Notices

## Minimal UI Free

Parts of the theme system, public layout patterns and chart wrapper in this
frontend are adapted from **Minimal UI Free** (`@minimal/material-kit-react`)
version **3.0.0**.

- Source: <https://github.com/minimal-ui-kit/material-kit-free>
- Pinned commit: `69e780a40c455d664b2e13c525faf1d492a072a7`
- Demo: <https://free.minimals.cc/>
- License: MIT

Local adaptations: system font stack instead of runtime font downloads, square
corners, enlarged type scale and chart typography, light-only color scheme, and
removal of account/shop/blog/notification/language-switch/promo features.
Template runtime dependencies such as `@iconify/react`, `simplebar-react` and
`@fontsource` are not used.
